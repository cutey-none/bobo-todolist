## 已验证但未留图的项

- **F4 拖拽改象限**：把「确认今日发布窗口」从「重要且紧急」拖到「重要但不紧急」后，辅助功能树显示计数由 3/4、0/1 变为 4/5、0/1，任务出现在目标象限。
- **面板内键盘**：`↑ ↓` 选中任务（行高亮 + 出现操作入口）、`Space` 完成、`⌘⌫` 删除、`⌘Z` 撤销、`Esc` 收起、`Tab` 切换象限、`⌘N` 新建。
- **菜单栏**：状态栏图标可展开 / 收起 / 钉住 / 切贴边侧 / 置顶 / 全屏显示 / 设置 / 退出。
- **全局快捷键**：启动日志确认 `RegisterEventHotKey` 返回 noErr（`全局快捷键已注册 ⌥ Space`）。

## 未能自动验证的项（需人工按键确认）

- **⌥Space 实际按键**：合成按键（AX 与 HID 两种方式）都无法触发系统级 Carbon 热键，注册本身已确认成功；请手动按一次 ⌥Space 确认。
- **鼠标悬停任务行浮出「…」**：SwiftUI 悬停依赖真实指针移动，自动化工具走的是辅助功能点击，无法稳定复现；界面已实现（键盘选中时同样会显示「…」入口）。
- **其他 App 全屏时自动隐藏**：需要真实进入全屏 Space 才能触发，未自动验证。

## 验证过程中发现并修复的缺陷

1. **面板展开后不移动**：`@Published` 在赋值前发通知，导致用旧值计算窗口位置（改为使用通知携带的新值）。
2. **收起态完全不可见**：贴边条画在窗口离屏一侧（修正左右缘的对齐与收起坐标）。
3. **删除不落盘**：写操作使用独立 `ModelContext`，与 `@Query` 的 mainContext 不一致，`delete` 无效（统一为 mainContext，数据库行数已复核）。
4. **点「新建任务」无法直接输入**：面板没有成为键盘焦点，且焦点时序早于窗口激活（改为先激活窗口、下一轮 runloop 再要焦点）。
5. **⌘, 打开空白设置窗口**：SwiftUI 空 `Settings` 场景抢占快捷键（改为场景内直接承载真实设置界面，删除自建设置窗口）。
6. **切到左缘后收起位置错误**：macOS 会把负 x 的窗口动画强制约束回屏幕内（左侧收起改用确定性的 `setFrameOrigin`，实测 x=−522，只露出 38pt rail）。
7. **拖到新边缘后多个动画互相覆盖**：`isDocked / edge / isExpanded` 连续发布时各自触发布局（吸附提交期间暂停中间布局，只执行一次最终布局）。
8. **松手吸附后立即被悬停重新展开**：鼠标仍压在刚出现的 rail 上，120ms 后会自动展开（现在会等待鼠标先离开 rail，下一次重新悬停才展开）。
