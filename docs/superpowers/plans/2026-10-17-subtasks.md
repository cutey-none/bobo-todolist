# 子待办 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 待办可以拆出一层子待办，在主面板展开行和编辑浮层中即时勾选、添加、改名、删除（可撤销）、排序和提升为独立待办；父待办行显示进度。

**Architecture:** 新增 SwiftData 实体 `SubtaskItem`（以 `parentID` 关联父待办，`TaskItem` 不改字段）。读写集中在 `TaskRepository` 的扩展中，沿用「立即保存、失败回滚字段」的模式；`AppState` 把子待办操作接入现有撤销队列（`UndoEntry` 改为多种类型）。界面上由一个自带 `@Query` 的 `SubtaskListView` 在任务行展开区和编辑浮层复用，经自定义环境值拿到 `AppState`；`RootView` 用 `@Query` 汇总进度传给任务行。

**Tech Stack:** Swift 5.9、SwiftUI、SwiftData、XCTest，macOS 14+。

**Spec:** `docs/superpowers/specs/2026-10-17-subtasks-design.md`

## Global Constraints

- 子待办只有一层；没有描述、象限或截止时间；随父待办。
- 父子完成状态互不自动联动。
- 子待办标题规则 = `TaskTitle.validate`（去首尾空白、非空、≤ 200 字、换行转空格）。
- 所有子待办写入立即保存；保存失败回滚到写入前状态并提示。`TaskRepository.simulatesSaveFailure` / `QT_FAIL_SAVES=1` 模拟失败。
- 撤销窗口沿用 `Metrics.undoWindow`（8 秒）与现有撤销队列。
- 描述 Markdown 与 `- [ ]` 规则不变，永不解析为子待办。
- 子待办不出现在象限列表、顶栏计数、已完成计数中。
- 不引入第三方依赖；不修改 `TaskItem` 的存储字段。
- 新代码注释与界面文案用中文，风格与现有代码一致。

## Review Focus

1. **旧数据库升级**：用户已有的 `Tasks.store`（无子待办表）必须原样打开；否则 `PersistenceController` 会把库改名为 `.broken-*` 并以空库启动。→ Task 1 `testStoreFromBeforeSubtasksOpensWithDataIntact`，Task 8 用真实库副本验证。
2. **撤销时父待办已不在**：先删子待办（或提升），再删父待办，然后撤销子待办——不得生成孤儿子待办，应提示无法撤销并移出队列。→ Task 4 `testUndoSubtaskAfterParentDeletedIsDroppedWithNotice`。
3. **删除父待办后撤销**：子待办的标题、完成状态与顺序都要回来。→ Task 3 `testDeletingParentRemovesSubtasksAndUndoRestoresThem`。
4. **保存失败**：添加、改名、勾选、排序、删除、提升在写入失败时都回到原状态（尤其排序时其他兄弟的 sortOrder）。→ Task 2 `testFailedReorderRestoresSiblingOrder`、Task 3 `testFailedPromotionLeavesEverythingInPlace`。
5. **Esc 在子待办输入框中**：只取消改名 / 清空输入，不得收起面板或关闭编辑浮层。→ Task 5 运行验证步骤与 Task 4 的 `focusedSubtaskField` 标志测试 `testSubtaskFieldFocusIsTracked`。

import Foundation
import SwiftData

/// 子待办（PRD 15）：只有一层，没有描述与象限，随父待办显示，靠 parentID 关联。
@Model
final class SubtaskItem {
    @Attribute(.unique) var id: UUID
    var parentID: UUID
    var title: String
    var isCompleted: Bool
    var completedAt: Date?
    var sortOrder: Int
    var createdAt: Date
    var updatedAt: Date

    init(
        id: UUID = UUID(),
        parentID: UUID,
        title: String,
        isCompleted: Bool = false,
        completedAt: Date? = nil,
        sortOrder: Int = 0,
        createdAt: Date = Date(),
        updatedAt: Date = Date()
    ) {
        self.id = id
        self.parentID = parentID
        self.title = title
        self.isCompleted = isCompleted
        self.completedAt = completedAt
        self.sortOrder = sortOrder
        self.createdAt = createdAt
        self.updatedAt = updatedAt
    }
}

/// 删除或提升后可撤销的快照；index 是当时在父待办中的位置。
struct SubtaskSnapshot: Equatable {
    let id: UUID
    let parentID: UUID
    let title: String
    let isCompleted: Bool
    let completedAt: Date?
    let createdAt: Date
    let index: Int

    init(_ item: SubtaskItem, index: Int) {
        id = item.id
        parentID = item.parentID
        title = item.title
        isCompleted = item.isCompleted
        completedAt = item.completedAt
        createdAt = item.createdAt
        self.index = index
    }

    func makeSubtask(sortOrder: Int) -> SubtaskItem {
        SubtaskItem(
            id: id,
            parentID: parentID,
            title: title,
            isCompleted: isCompleted,
            completedAt: completedAt,
            sortOrder: sortOrder,
            createdAt: createdAt
        )
    }
}

/// 父待办行上的进度胶囊。
struct SubtaskProgress: Equatable {
    let done: Int
    let total: Int

    var isComplete: Bool { done == total }
}

import Foundation
import SwiftData

/// 子待办读写（PRD 15）：与事项一样立即保存，失败时回滚字段并返回失败。
extension TaskRepository {
    func allSubtasks() -> [SubtaskItem] {
        (try? context.fetch(FetchDescriptor<SubtaskItem>())) ?? []
    }

    func subtasks(of parentID: UUID) -> [SubtaskItem] {
        let descriptor = FetchDescriptor<SubtaskItem>(predicate: #Predicate { $0.parentID == parentID })
        return Self.ordered((try? context.fetch(descriptor)) ?? [])
    }

    /// sortOrder 升序，其次创建时间升序。
    static func ordered(_ items: [SubtaskItem]) -> [SubtaskItem] {
        items.sorted { lhs, rhs in
            if lhs.sortOrder != rhs.sortOrder { return lhs.sortOrder < rhs.sortOrder }
            return lhs.createdAt < rhs.createdAt
        }
    }

    static func progress(of subtasks: [SubtaskItem]) -> [UUID: SubtaskProgress] {
        Dictionary(grouping: subtasks, by: \.parentID).mapValues { items in
            SubtaskProgress(done: items.filter(\.isCompleted).count, total: items.count)
        }
    }

    func task(withID id: UUID) -> TaskItem? {
        var descriptor = FetchDescriptor<TaskItem>(predicate: #Predicate { $0.id == id })
        descriptor.fetchLimit = 1
        return (try? context.fetch(descriptor))?.first
    }

    /// 标题不合法或保存失败时返回 nil，且不留下任何子待办。
    @discardableResult
    func addSubtask(title: String, to parentID: UUID) -> SubtaskItem? {
        guard case .success(let valid) = TaskTitle.validate(title) else { return nil }
        let next = (subtasks(of: parentID).map(\.sortOrder).max() ?? -1) + 1
        let item = SubtaskItem(parentID: parentID, title: valid, sortOrder: next)
        context.insert(item)
        return save() ? item : nil
    }

    @discardableResult
    func renameSubtask(_ item: SubtaskItem, to title: String) -> Bool {
        guard case .success(let valid) = TaskTitle.validate(title) else { return false }
        return persistSubtasks([item]) {
            item.title = valid
            item.updatedAt = Date()
        }
    }

    /// 只切换子待办自身；父待办的完成状态不受影响（父子不联动）。
    @discardableResult
    func toggleSubtask(_ item: SubtaskItem) -> Bool {
        persistSubtasks([item]) {
            item.isCompleted.toggle()
            item.completedAt = item.isCompleted ? Date() : nil
            item.updatedAt = Date()
        }
    }

    /// 「上移 / 下移」：越界时停在两端。
    @discardableResult
    func moveSubtask(_ item: SubtaskItem, by delta: Int) -> Bool {
        let list = subtasks(of: item.parentID)
        guard let index = list.firstIndex(where: { $0.id == item.id }) else { return false }
        let target = min(max(index + delta, 0), list.count - 1)
        guard target != index else { return true }
        var reordered = list
        reordered.remove(at: index)
        reordered.insert(item, at: target)
        return resequence(reordered, touching: list)
    }

    /// 拖拽：放到 targetID 之前；targetID 为 nil 或不在同一父待办时放到末尾。
    @discardableResult
    func moveSubtask(_ item: SubtaskItem, before targetID: UUID?) -> Bool {
        let list = subtasks(of: item.parentID)
        var reordered = list.filter { $0.id != item.id }
        guard reordered.count == list.count - 1 else { return false }
        let index = targetID.flatMap { id in reordered.firstIndex { $0.id == id } } ?? reordered.count
        reordered.insert(item, at: index)
        return resequence(reordered, touching: list)
    }

    private func resequence(_ ordered: [SubtaskItem], touching items: [SubtaskItem]) -> Bool {
        persistSubtasks(items) {
            for (order, item) in ordered.enumerated() where item.sortOrder != order {
                item.sortOrder = order
                item.updatedAt = Date()
            }
        }
    }

    /// 修改已有子待办并保存；保存失败时逐一恢复字段（SwiftData 的 rollback 不还原已加载对象的属性）。
    func persistSubtasks(_ items: [SubtaskItem], _ change: () -> Void) -> Bool {
        let before = items.map { (item: $0, fields: SubtaskFields($0)) }
        change()
        guard save() else {
            for entry in before { entry.fields.apply(to: entry.item) }
            return false
        }
        return true
    }
}

/// 子待办可变字段的快照，用于保存失败时还原。
struct SubtaskFields {
    let title: String
    let isCompleted: Bool
    let completedAt: Date?
    let sortOrder: Int
    let updatedAt: Date

    init(_ item: SubtaskItem) {
        title = item.title
        isCompleted = item.isCompleted
        completedAt = item.completedAt
        sortOrder = item.sortOrder
        updatedAt = item.updatedAt
    }

    func apply(to item: SubtaskItem) {
        item.title = title
        item.isCompleted = isCompleted
        item.completedAt = completedAt
        item.sortOrder = sortOrder
        item.updatedAt = updatedAt
    }
}

    /// 删除成功返回带原位置的快照；保存失败时子待办保留，返回 nil。
    func deleteSubtask(_ item: SubtaskItem) -> SubtaskSnapshot? {
        let snapshot = SubtaskSnapshot(item, index: index(of: item))
        context.delete(item)
        return save() ? snapshot : nil
    }

    /// 放回原父待办的原位置；父待办已不存在时不恢复，返回 false。
    @discardableResult
    func restoreSubtask(_ snapshot: SubtaskSnapshot) -> Bool {
        guard task(withID: snapshot.parentID) != nil else { return false }
        let siblings = subtasks(of: snapshot.parentID)
        return persistSubtasks(siblings) { insert(snapshot, among: siblings) }
    }

    /// 提升为独立待办：在父待办所在象限新建事项（保留标题与完成状态），并移除该子待办。
    func promoteSubtask(_ item: SubtaskItem) -> (task: TaskItem, snapshot: SubtaskSnapshot)? {
        guard let parent = task(withID: item.parentID) else { return nil }
        let snapshot = SubtaskSnapshot(item, index: index(of: item))
        let promoted = TaskItem(
            title: item.title,
            quadrant: parent.quadrant,
            isCompleted: item.isCompleted,
            completedAt: item.completedAt,
            sortOrder: endSortOrder(in: parent.quadrant, from: allTasks())
        )
        context.insert(promoted)
        context.delete(item)
        return save() ? (promoted, snapshot) : nil
    }

    /// 撤销提升：删除新建的待办（若仍存在），把子待办放回原位置；父待办已不存在时返回 false。
    @discardableResult
    func undoPromotion(_ snapshot: SubtaskSnapshot, promotedTaskID: UUID) -> Bool {
        guard task(withID: snapshot.parentID) != nil else { return false }
        let siblings = subtasks(of: snapshot.parentID)
        return persistSubtasks(siblings) {
            if let promoted = task(withID: promotedTaskID) { context.delete(promoted) }
            insert(snapshot, among: siblings)
        }
    }

    private func index(of item: SubtaskItem) -> Int {
        let list = subtasks(of: item.parentID)
        return list.firstIndex { $0.id == item.id } ?? list.count
    }

    /// 插入快照并重排兄弟顺序（不保存，由调用方的 persistSubtasks 负责）。
    private func insert(_ snapshot: SubtaskSnapshot, among siblings: [SubtaskItem]) {
        let item = snapshot.makeSubtask(sortOrder: 0)
        context.insert(item)
        var ordered = siblings
        ordered.insert(item, at: min(max(snapshot.index, 0), ordered.count))
        for (order, sibling) in ordered.enumerated() { sibling.sortOrder = order }
    }

    func moveSubtask(_ item: SubtaskItem, before targetID: UUID?) {
        if !repository.moveSubtask(item, before: targetID) { show("移动失败，请重试", isError: true) }
    }

    func deleteSubtask(_ item: SubtaskItem) {
        let title = item.title
        guard let snapshot = repository.deleteSubtask(item) else {
            show("删除失败，请重试", isError: true)
            return
        }
        enqueueUndo(UndoEntry(kind: .subtask(snapshot), title: title))

            show("提升失败，请重试", isError: true)
            return
        }
        enqueueUndo(UndoEntry(kind: .promotion(result.snapshot, promotedTaskID: result.task.id), title: title))

import SwiftData
import SwiftUI

private struct AppStateKey: EnvironmentKey {
    static let defaultValue: AppState? = nil
}

extension EnvironmentValues {
    /// 主面板与编辑浮层注入的 AppState；独立渲染的任务行（如测试）没有子待办区。
    var appState: AppState? {
        get { self[AppStateKey.self] }
        set { self[AppStateKey.self] = newValue }

}

/// 子待办拖拽载荷：带前缀，事项的拖放目标解析不出 UUID，会忽略它。
enum SubtaskDrag {
    private static let prefix = "subtask:"

    static func payload(_ id: UUID) -> String { prefix + id.uuidString }

    static func id(from raw: String) -> UUID? {
        guard raw.hasPrefix(prefix) else { return nil }
        return UUID(uuidString: String(raw.dropFirst(prefix.count)))
    }
}

enum SubtaskField: Hashable {
    case add
    case rename(UUID)
}

/// 子待办列表（PRD 15）：主面板展开区与编辑浮层共用，所有修改立即保存。
struct SubtaskListView: View {
    let parentID: UUID
    let state: AppState
    @Query private var items: [SubtaskItem]

    @State private var draft = ""
    @State private var draftProblem: String?
    @State private var editingID: UUID?
    @State private var editingText = ""
    @State private var editingProblem: String?
    @State private var targetedID: UUID?
    @State private var inputToken = UUID()
    @FocusState private var focus: SubtaskField?

    init(parentID: UUID, state: AppState) {
        self.parentID = parentID
        self.state = state
        let id = parentID
        _items = Query(
            filter: #Predicate<SubtaskItem> { $0.parentID == id },
            sort: [SortDescriptor(\.sortOrder), SortDescriptor(\.createdAt)]
        )
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 0) {
            ForEach(items) { item in
                SubtaskRowView(
                    item: item,
                    isEditing: editingID == item.id,
                    editingText: $editingText,
                    problem: editingID == item.id ? editingProblem : nil,
                    focus: $focus,
                    isTargeted: targetedID == item.id,
                    onToggle: { withAnimation(.easeOut(duration: 0.15)) { state.toggleSubtask(item) } },
                    onBeginEdit: { beginEdit(item) },
                    onCommitEdit: commitEdit,
                    onCancelEdit: cancelEdit,
                    onDelete: { withAnimation(.easeOut(duration: 0.15)) { state.deleteSubtask(item) } },
                    onPromote: { withAnimation(.easeOut(duration: 0.18)) { state.promoteSubtask(item) } },
                    onMove: { delta in withAnimation(.easeOut(duration: 0.15)) { state.moveSubtask(item, by: delta) } },
                    onDrop: { raw in drop(raw, before: item.id) },
                    onTargeted: { targetedID = $0 ? item.id : (targetedID == item.id ? nil : targetedID) }
                )
            }
            addRow
        }
        .onChange(of: hasPendingInput) { _, pending in
            if pending { state.activeSubtaskInputs.insert(inputToken) } else { state.activeSubtaskInputs.remove(inputToken) }
        }
        .onChange(of: focus) { old, new in
            state.focusedSubtaskField = new != nil
            // 改名输入框失焦即保存。
            if case .rename(let id)? = old, new != old, editingID == id { commitEdit() }
        }
        .onDisappear {
            state.activeSubtaskInputs.remove(inputToken)
            if focus != nil { state.focusedSubtaskField = false }
        }
    }

    private var hasPendingInput: Bool {
        editingID != nil || !draft.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty
    }

    private var addRow: some View {
        VStack(alignment: .leading, spacing: 2) {
            HStack(spacing: 6) {
                Image(systemName: "plus")
                    .font(.system(size: 10, weight: .medium))
                    .foregroundStyle(Theme.tertiaryText)
                    .frame(width: 36)
                TextField("添加子待办…", text: $draft)
                    .textFieldStyle(.plain)
                    .font(.system(size: 12))
                    .focused($focus, equals: .add)
                    .onSubmit(submitDraft)
                    .onExitCommand { draft = ""; draftProblem = nil }
                    .onChange(of: draft) { _, text in
                        draftProblem = TaskTitle.validate(text) == .failure(.tooLong) ? TaskTitle.Problem.tooLong.message : nil
                    }
                    .accessibilityLabel("添加子待办")
            }
            .frame(minHeight: 26)
            .dropDestination(for: String.self) { raws, _ in
                raws.first.map { drop($0, before: nil) } ?? false
            }
            if let draftProblem {
                Text(draftProblem)
                    .font(.system(size: 10.5))
                    .foregroundStyle(Theme.red)
                    .padding(.leading, 42)
            }
        }
    }

    private func submitDraft() {
        if let problem = state.addSubtask(draft, to: parentID) {
            draftProblem = problem
            return
        }
        draft = ""
        draftProblem = nil
        focus = .add
    }

    private func beginEdit(_ item: SubtaskItem) {
        if editingID != nil { commitEdit() }
        editingID = item.id
        editingText = item.title
        editingProblem = nil
        focus = .rename(item.id)
    }

    private func commitEdit() {
        guard let id = editingID, let item = items.first(where: { $0.id == id }) else {
            editingID = nil
            return
        }
        if let problem = state.renameSubtask(item, to: editingText) {
            editingProblem = problem
            return
        }
        editingID = nil
        editingProblem = nil
    }

    private func cancelEdit() {
        editingID = nil
        editingProblem = nil
        focus = nil
    }

    /// 只接受同一父待办的子待办；事项或其他父待办的子待办一律拒绝。
    private func drop(_ raw: String, before targetID: UUID?) -> Bool {
        targetedID = nil
        guard let id = SubtaskDrag.id(from: raw), let item = items.first(where: { $0.id == id }) else { return false }
        guard id != targetID else { return true }
        withAnimation(.easeOut(duration: 0.15)) { state.moveSubtask(item, before: targetID) }
        return true
    }
}
