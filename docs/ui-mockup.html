三、快速添加态 / 任务编辑态 / 象限空状态

三个高频局部交互的近景

③ 快速添加输入态

全局快捷键唤起后输入框直接聚焦，用 !1–!4 或点击色块指定象限，回车即建并自动收回贴边。

准备季度复盘材料
!1 重要紧急 !2 重要不紧急 !3 不重要紧急 !4 不重要不紧急
↩ 保存 Tab 切象限 Esc 取消 默认落入所选象限，插到未完成区顶部

④ 任务编辑态

点击任务卡片任意位置进入编辑；象限用四色分段控件切换，改完即迁移到目标象限。

四、尺寸、色板与交互标注

实现时按此表取值

1贴边条（收起态）

  • 尺寸 32 × 88pt，圆角 12pt（外侧不圆角）
  • 贴屏幕右缘（或左缘）垂直居中，可沿边缘上下拖动
  • 内容：四色小方块图标 + 未完成总数徽标
  • 悬停 120ms 后自动展开；移出 350ms 后收起
  • 系统全屏 App / 切 Space 时保持置顶可见

2展开面板

  • 默认 560 × 470pt，最小 420 × 320pt，圆角 16pt
  • 材质：系统毛玻璃 backdrop-blur 30px / saturate 180%
  • 阴影 0 24 60 rgba(0,0,0,.30)，边框 0.5pt 高光
  • 顶部：快速添加输入条 + 钉住 / 最小化 / 关闭
  • 展开动效：scale .98 → 1 + 透明度，220ms ease-out

3四象限与任务卡片

  • 2×2 等分网格，象限间距 8pt，内边距 8pt，每格最小高 150pt
  • 象限标题 11pt / 600，右上角显示未完成计数
  • 任务卡片高 30pt，圆角 8pt，标题 12pt 单行省略
  • 悬停显示拖拽手柄 ⠿ 与删除 ✕；拖拽可跨象限
  • 已完成任务收进底部「已完成 (n)」折叠条，默认收起
