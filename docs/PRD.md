## 一、产品概述

### 1.1 产品定位

一款 macOS 桌面端的极简待办工具，以「常驻贴边悬浮窗 + 四象限矩阵」为核心形态。用户无需离开当前工作即可快速捕捉任务，并用「重要 × 紧急」矩阵一眼看清「现在该做什么」。

### 1.2 目标用户

- 需要快速记录零散任务的办公 / 学习人群
- 希望工具常驻桌面、不想频繁切换 App 的人
- 习惯用四象限（Eisenhower 矩阵）做个人任务管理的人

### 1.3 核心价值

- **随手记**：全局快捷键唤起，几秒内完成一条任务
- **不打扰**：贴边收起，不占屏幕、不抢焦点
- **一眼懂**：四象限 + 未完成优先，优先级直接可见

### 1.4 一句话愿景

让任务捕捉快过遗忘，让「先做什么」一眼可见。

---

## 二、核心场景

**场景 1 · 工作间隙快速捕捉**

用户正在开会或写代码时想到一件事，按全局快捷键唤出悬浮窗，输入标题、用 `!2` 指定象限、回车保存，窗口自动收回贴边，不打断当前工作。

**场景 2 · 开始工作前做规划**

用户展开悬浮窗，在四象限里看到全部未完成任务：先处理「重要且紧急」，完成后打勾，任务自动收进「已完成」折叠区；再对「重要但不紧急」的任务做安排。

**场景 3 · 收工前清点**

用户把已完成的任务逐条勾掉，贴边条上的未完成计数从 8 降到 2，一眼看出今天还剩什么。

## 三、MVP 功能需求（v0.1）

### F1 贴边悬浮窗

- 常驻桌面，默认贴屏幕右边缘，收起后只露出一个窄条。
- 支持设置贴边侧（左 / 右，默认右）。
- 置顶显示（always-on-top），可在设置中关闭；非激活状态下点击面板不抢键盘焦点。

### F2 展开 / 收起

- 鼠标悬停到贴边条时展开为完整四象限面板。
- 鼠标移出且无交互后延迟收回。
- 全局快捷键在「展开 / 收起」间切换。
- 菜单栏图标可手动展开、隐藏或「钉住」面板。

### F3 四象限视图

- 2×2 矩阵布局，位置与语义色固定（见 4.1）。
- 每个象限展示该象限的**未完成任务**，已完成任务折叠在底部。
- 象限头部显示该象限未完成任务数。

### F4 任务管理

- **新建**：标题必填，象限必选（默认「重要且紧急」），备注可选。
- **编辑**：修改标题、备注、象限。
- **删除**：悬停显示删除入口，删除后提供 5 秒「撤销」。
- **完成 / 取消完成**：点击勾选框切换；完成后移入该象限「已完成」折叠区，贴边条计数减 1。
- **拖拽改象限**：任务可跨象限拖动，也支持拖动改变象限内顺序。

### F5 快速添加

- 全局快捷键唤起输入框并自动聚焦。
- 输入标题后回车即创建。
- 支持用 `!1`–`!4` 前缀或色块快速指定象限，`Tab` 循环切换，`Esc` 取消。

### F6 本地持久化

- 本地存储，启动即恢复上次数据。
- 无需登录，完全离线可用。

## 四、详细功能规格

### 4.1 象限定义与判定规则

| 位置 | 象限 | 语义色 | 含义 | 典型例子 |
| --- | --- | --- | --- | --- |
| 左上 | 重要且紧急 | 红 `#E5484D` | 有明确截止、且不做会有后果 | 今天 18:00 的交周报、线上故障 |
| 右上 | 重要但不紧急 | 蓝 `#3B82F6` | 长期有价值、无硬截止 | 学新框架、健身计划、季度复盘 |
| 左下 | 不重要但紧急 | 橙 `#F59E0B` | 有截止但价值低、可委托 | 回会议室预约邮件、帮同事确认排期 |
| 右下 | 不重要且不紧急 | 灰 `#6B7280` | 无截止、低价值 | 刷资讯、整理桌面 |

**判定口径**：

- 「重要」= 不做会影响目标达成或他人对你的承诺。
- 「紧急」= 有明确截止时间，或延迟会立刻产生后果（≥ 24 小时内到期的任务默认视为紧急）。
- 若用户未指定且无法判定，默认落入「重要且紧急」——宁可让它显眼，也不要让它消失。
- 用户手动指定的象限**永远优先于**任何自动推断，系统不自动改任务象限（v0.1 不做自动重排）。

> 原始需求中第四象限被写成「重要不紧急」，属笔误；本文档按标准艾森豪威尔矩阵口径统一为「不重要且不紧急」。

### 4.2 象限内排序规则（写死）

未完成区：

1. 先按 `sortOrder` 升序（用户手动拖拽产生的顺序）
2. `sortOrder` 相同时，按创建时间倒序（新建的任务在上面）
3. 新任务默认插到该象限未完成区的**顶部**

已完成区（折叠后展开时）：

1. 先按 `completedAt` 倒序（最近完成的在上面）
2. 再按创建时间倒序

### 4.3 贴边与窗口行为

| 项目 | 规格 |
| --- | --- |
| 贴边侧 | 左 / 右可选，默认右；切换后贴边条在 0.2s 内移动到新边缘 |
| 吸附阈值 | 拖拽至距屏幕边缘 24pt 内自动吸附；拖离 48pt 以上脱离 |
| 贴边条位置 | 默认垂直居中，可沿边缘上下拖动；位置随屏幕分辨率变化自动夹取到可见区域 |
| 置顶 | 默认开启 always-on-top，设置中可关闭 |
| 多显示器 | 贴边条跟随「最后活跃的屏幕」；显示器拔出时回到主屏右缘 |
| 全屏 App / Space | 默认在其他 App 全屏时**隐藏**贴边条，退出全屏后恢复；用户可在设置中改为「全屏时也显示」 |
| 隐藏 / 显示 | 菜单栏图标或全局快捷键可隐藏整个 App；隐藏后全局快捷键仍可唤起 |
| 退出 | 菜单栏图标右键 → 退出；无 Dock 图标（`LSUIElement`），不占 Dock 位置 |

### 4.4 展开 / 收起触发

| 触发方式 | 行为 |
| --- | --- |
| 鼠标悬停贴边条 | 停留 120ms 后展开（防误触） |
| 鼠标移出面板 | 停留 350ms 后收起；鼠标在输入框内或有拖拽进行中则不收起 |
| 全局快捷键 | 展开 ⇄ 收起切换 |
| 菜单栏点击 | 展开并聚焦输入框 |
| 点击「钉住」 | 保持展开，忽略移出收起；再次点击取消 |
| 点击「最小化」 | 立即收起贴边 |
| 点击「关闭」 | 隐藏 App，保留菜单栏图标 |

### 4.5 快捷键

| 功能 | 快捷键 |
| --- | --- |
| 展开 / 收起悬浮窗 | `⌥ + Space`（可在设置中修改） |
| 新建任务（面板内） | `⌘ + N` |
| 完成 / 取消完成选中任务 | `Space` |
| 切换象限 | `Tab` 循环选中 |
| 删除选中任务 | `⌘ + ⌫` |
| 取消输入 / 关闭面板 | `Esc` |

### 4.6 任务操作细则

- 新建后输入框清空并保持聚焦，支持连续录入多条。
- 勾选完成时播放 0.18s 勾选动画，任务卡片淡出并移入该象限「已完成 (n)」折叠区。
- 取消完成时，任务回到未完成区顶部。
- 删除需二次确认（`⌘ + Z` 或点击「撤销」可在 5 秒内恢复）。
- 拖拽跨象限时目标象限高亮描边，释放后立即写入 `quadrant`。

## 五、数据结构与存储

### 5.1 数据模型

```text
Task {
  id: UUID
  title: String                    // 必填，最长 200 字
  note: String?                    // 可选备注
  quadrant: Quadrant               // importantUrgent / importantNotUrgent /
                                   // notImportantUrgent / notImportantNotUrgent
  isCompleted: Bool
  createdAt: Date
  completedAt: Date?               // 完成时间，用于已完成区排序
  dueAt: Date?                     // 可选截止时间
  sortOrder: Int                   // 象限内手动排序权重
  updatedAt: Date
}

Settings {
  edge: left | right               // 贴边侧
  peekOffset: Double               // 贴边条沿边缘的偏移
  alwaysOnTop: Bool
  showInFullScreen: Bool
  hotkey: String                   // 全局快捷键
}
```

### 5.2 选型：SwiftData

- **理由**：SwiftUI 原生集成、零第三方依赖、支持迁移与查询排序（象限内排序规则可直接用 `@Query` + `SortDescriptor` 表达）；本地 SQLite 落盘，重启恢复快，无需手写序列化与并发保护。
- **备选**：单个 JSON 文件（`Application Support/…/tasks.json`）。实现更简单，但排序、迁移、并发写入都要自己处理，仅在 SwiftData 不可用时降级使用。
- **写入时机**：任何增删改立即保存（数据量小，无需批量合并）。
- **备份**：数据位于 `~/Library/Application Support/<AppName>/`，MVP 不做导出。

## 六、非功能需求

- **技术选型**：SwiftUI + SwiftData（原生、轻量，对贴边窗口、毛玻璃 vibrancy、菜单栏、全局快捷键等 macOS 特性支持最好）。Electron 内存占用高，MVP 阶段不推荐。
- **性能**：冷启动 < 1s；常驻内存 < 100MB；展开 / 收起动画稳定 60fps；1000 条任务时滚动不掉帧。
- **离线**：完全本地，无任何网络请求。
- **隐私**：数据只存本机，无遥测、无账号、无崩溃上报。
- **无障碍**：全键盘可操作；VoiceOver 可朗读象限名、任务标题与完成状态；文字与背景对比度 ≥ 4.5:1；支持系统「减少动态效果」。
- **外观**：跟随系统浅色 / 深色，不提供自定义主题。

## 八、验收标准

**贴边与展开**

- Given App 已启动，When 用户把窗口拖到屏幕右缘 24pt 内，Then 窗口吸附为 32×88pt 的贴边条并垂直居中。
- Given 处于贴边收起态，When 鼠标悬停在贴边条上超过 120ms，Then 面板在 220ms 内展开，且输入框未自动抢焦点。
- Given 面板已展开且输入框为空，When 鼠标移出面板 350ms，Then 面板自动收回贴边条。
- Given 面板已展开且输入框内有未保存文本，When 鼠标移出面板，Then 面板收回且文本保留为草稿，下次展开时仍在。
- Given 面板已钉住，When 鼠标移出面板 10 秒，Then 面板保持展开。

**四象限增删改**

- Given 面板已展开，When 用户在「重要但不紧急」象限点击「+ 添加任务」并输入标题后回车，Then 新任务出现在该象限未完成区顶部，计数 +1。
- Given 某象限内有一条任务，When 用户点击其标题区域并修改标题后保存，Then 卡片标题立即更新；重启 App 后仍是新标题。
- Given 某象限内有一条任务，When 用户悬停该卡片并点击删除，Then 卡片消失并在浮层提供 5 秒「撤销」。
- Given 某象限内有一条任务，When 用户将其拖到另一象限并释放，Then 该任务出现在目标象限未完成区顶部，两个象限计数同步更新。

**完成态**

- Given 某象限有 3 条未完成任务，When 用户勾选其中一条，Then 该任务在 0.18s 动画后移入该象限「已完成 (n)」折叠条，计数变为 2 / 已完成变为 1，贴边条未完成总数减 1。
- Given 某任务已折叠在「已完成」区，When 用户点开折叠条并取消勾选，Then 任务回到该象限未完成区顶部。
- Given 象限无未完成任务，Then 该象限保留虚线占位与「+ 添加任务」入口，不隐藏。

**持久化与窗口行为**

- Given 用户已创建 5 条分布在不同象限的任务，When 退出并重新启动 App，Then 5 条任务的标题、象限、完成状态与排序完全一致，贴边条计数正确。
- Given 贴边条设置为右侧，When 用户切到左侧，Then 贴边条在 0.2s 内移动到屏幕左缘，重启后仍在左侧。
- Given 前置 App 进入全屏，When 用户查看屏幕，Then 贴边条默认隐藏；退出全屏后自动恢复。
- Given 用户按 `⌥ + Space`，Then 面板展开 / 收起可反复切换，无卡顿。

## 九、待确认问题

| # | 问题 | 推荐选项 | 理由 |
| --- | --- | --- | --- |
| 1 | 多显示器下贴边条固定在哪块屏？ | 跟随最后活跃屏幕 | 用户注意力在哪就跟到哪，避免"找不到窗口" |
| 2 | 其他 App 全屏时是否仍显示？ | 默认隐藏，可在设置开启 | 全屏通常意味着专注，默认不打扰 |
| 3 | 删除任务是否需要二次确认？ | 不弹窗，改为 5 秒可撤销 | 弹窗打断心流，撤销对误删的挽救成本更低 |
| 4 | 是否允许一条任务同时属于多个象限？ | 不允许，象限为单选 | 保持模型简单，多标签属于 v0.2 的标签能力 |
| 5 | 是否需要截止时间与提醒？ | v0.1 只保留可选截止时间字段，不做系统通知 | 通知涉及权限与打断，先验证四象限主流程 |

## 十二、UI 方案

> 完整可视化设计稿见 `docs/ui-mockup.html`（浏览器打开）与 `docs/ui-mockup.png`，包含深色 / 浅色两套色板下的 5 种状态：贴边收起态、展开四象限态、快速添加输入态、任务编辑态、象限空状态。

### 12.1 信息架构

```text
贴边条（收起态）
   ↓ 悬停 / 快捷键 / 菜单栏
四象限面板（展开态）
   ↓ 点击任务 / 输入
快速添加输入框 · 任务编辑浮层
```

### 12.2 三种窗口状态

1. **贴边收起态**：屏幕边缘的窄条，仅露出四色图标和「未完成总数」徽标。
2. **展开悬浮态**：2×2 四象限面板，顶部为快速添加输入框。
3. **拖拽 / 吸边态**：拖拽中面板半透明，靠近边缘时显示吸附预览。

### 12.3 线框图

**贴边收起态（以右边缘为例）**

```text
                   屏幕右缘
                    ┌────────┐
                    │  ▦  5  │  ▦ = 四色图标，5 = 未完成总数
                    └────────┘
```

**展开悬浮态**

### 12.4 关键交互流程

**添加任务**

快捷键 / 点击「+」→ 输入框聚焦 → 输入标题 → 选择象限（`!1`–`!4` 或点击色块）→ 回车 → 任务出现在对应象限未完成区顶部。

**标记完成**

点击勾选框 → 0.18s 勾选动画 → 任务移入该象限「已完成 (n)」折叠区 → 贴边条徽标数减 1。

**切换象限**

拖拽任务到目标象限 → 目标象限高亮描边 → 释放 → 更新 `quadrant` → 目标象限未完成区置顶。
